# Daijing Shi · Personal website

简洁的静态学术主页：个人简介、教育经历、一行研究兴趣和三篇论文。
白底黑字，无动画、卡片或第三方依赖。默认英文，可切换中文。
双击 index.html 即可预览。

## 更新已有网站

将本文件夹内部文件上传至 carabdis/carabdis.github.io 仓库根目录，覆盖同名文件。
根目录应直接包含 index.html 和 assets，不要再套一层文件夹，也不要只上传 ZIP。
提交到当前发布分支 main，等待部署完成即可，无需重新配置 Pages。
访问 https://carabdis.github.io/；若仍显示旧版，使用无痕窗口或强制刷新。

## 文件与内容维护

- index.html：正文、教育经历、论文，以及 data-zh 属性中的中文翻译。
- assets/style.css：简洁排版与手机适配。
- assets/site.js：中英文切换。
- .nojekyll：静态发布标记。
- assets/favicon.svg：保留的旧版图标，新版未引用。

三篇论文沿用原有题目、作者与链接。MCHA 尚无已确认的正式发表信息，
因此保留 Research manuscript, 2026 标注；确认会议或期刊后可直接更新。
未附带论文 PDF 或其他私人文件。
